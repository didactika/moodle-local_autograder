**Requisitos:** Moodle 5.3 y PHP 8.3 o posterior para la rama `main`. Moodle 4.0 a 5.2 tienen una línea propia con las mismas funciones.

| Moodle | Rama | Versiones |
|---|---|---|
| 4.0 a 5.2 | `MOODLE_400_STABLE` | `X.Y.Z-m400` |
| 5.3 | `main` | `X.Y.Z-m503` |

> [!IMPORTANT]
> La calificación se realiza con tareas programadas y tareas ad hoc, de modo que [cron](https://docs.moodle.org/es/Cron) debe ejecutarse con regularidad para que las calificaciones se asignen a tiempo.

Instale el [informe de Autograder](https://github.com/didactika/moodle-report_autograder) (`report_autograder`) junto con este plugin: el plugin califica y el informe es donde se revisan las decisiones.

<Tabs>
  <TabItem label="Desde una versión publicada">
    Descargue los ZIP de la última versión de Autograder y del informe, vaya a **Administración del sitio > Extensiones > Instalar plugins**, suba cada archivo y siga las indicaciones.
  </TabItem>
  <TabItem label="Desde Git">
```bash
cd /path/to/moodle
# Moodle 5.3
git clone https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone https://github.com/didactika/moodle-report_autograder.git report/autograder
# Moodle 4.0 a 5.2
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-local_autograder.git local/autograder
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-report_autograder.git report/autograder
php admin/cli/upgrade.php
```
  </TabItem>
</Tabs>

Tras la instalación, las tareas, los foros y los cuestionarios ya pueden usar Autograder. El siguiente paso es [calificar una primera actividad](page:getting-started/quick-start).
